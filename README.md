# PlayBeat CRM Platform

This application is a work in progress, not yet verified for sale.

## Local checks

1. Install Node.js and run `npm ci`.
2. Run `npx prisma generate`.
3. Run `npm run lint` and `npm run build`.
4. Configure environment variables outside source control.
5. Apply database migrations separately after reviewing changes on staging.

## Release checklist

Check login, authorization, CRM lead workflows, admin pages, deployed demo, repository license, third-party assets, and transfer rights before making sale-ready claims.
